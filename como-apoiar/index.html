Como apoiar

Transforme sua contribuição em impacto de longo prazo.

Escolha uma contribuição pontual ou uma recorrência mensal. O site organiza a experiência, enquanto a autenticação e a movimentação financeira permanecem no ambiente bancário.

Pix pontual

Escolha o valor e gere seu QR Code.

O QR Code é montado localmente no seu navegador. Nenhuma senha, conta bancária ou credencial de pagamento é enviada ao site.

Valor da contribuição

O QR Code será exibido aqui depois que a chave Pix oficial for configurada.

Contribuição

R$ 100,00

Escaneie com o aplicativo do seu banco. Antes de confirmar, confira se o recebedor exibido pelo banco corresponde ao Fundo Centenário.

Pix Automático

Autorize uma contribuição recorrente no ambiente do banco.

O site não cria a recorrência diretamente. O botão abaixo redireciona para uma experiência hospedada pelo banco ou PSP, onde a autorização acontece com as regras e autenticação do próprio provedor.

Valor mensal desejado
Contribuição mensal

R$ 100,00 por mês

O valor exibido pode ser encaminhado ao provedor somente se a URL hospedada dele documentar esse parâmetro. Caso contrário, o valor final será definido no ambiente bancário.

Segurança

O banco continua sendo o ambiente de pagamento.

Esta implementação evita processar dados financeiros sensíveis no site do Fundo.

  • 01
    O Pix pontual é preparado no navegador e confirmado no aplicativo do banco.
  • 02
    O Pix Automático só é iniciado por um redirecionamento para um domínio previamente autorizado do banco ou PSP.
  • 03
    Nenhuma senha, token privado, certificado ou client secret deve existir no JavaScript público.
Confira o recebedor no banco Associação Fundo Patrimonial Escola de Engenharia

O nome efetivamente mostrado ao pagador é retornado pelo DICT conforme a chave Pix utilizada.

Sem backend

O site não confirma o pagamento.

Após a leitura do QR Code, a transação acontece fora do navegador. Sem uma API e webhook, esta página não sabe se a contribuição foi concluída.

Pix estático

Não há credencial bancária no frontend.

Para gerar o BR Code são necessários apenas dados públicos do recebedor, como a chave Pix, nome e cidade.

Pix Automático

Use fluxo hospedado pelo provedor.

Se o banco exigir criação de recorrência via API, OAuth, mTLS ou segredo privado, será necessário adicionar uma função serverless ou backend.

O site organiza a experiência de contribuição. A efetivação financeira permanece no banco ou PSP.
